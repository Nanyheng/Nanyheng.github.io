# Nanyi Zheng — Academic Website

This repository contains the source for Nanyi Zheng's academic homepage. It is a dependency-free static site designed for GitHub Pages.

## Publish with GitHub Pages

1. Create a public GitHub repository named `Nanyheng.github.io`.
2. Upload the contents of this directory to the repository's default branch.
3. In **Settings → Pages**, choose **Deploy from a branch**, then select the default branch and the repository root.
4. The website will be available at `https://nanyheng.github.io/` after GitHub finishes deploying it.

The downloadable CV is stored at `files/CV_Nanyi_Zheng.pdf`. Replace that file whenever the CV is updated.
